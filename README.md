# 教师工资管理系统（TSMS）

这是一个基于 C 语言实现的小型教师工资管理系统，覆盖课程设计要求中的录入、查询、统计和修改功能。

## 功能

1. 教师信息及教师工资信息录入，并保存到 `data/teachers.csv` 文件。
2. 教师工资查询：
   - 按教师编号查询。
   - 按所在部门查询。
   - 查询结果会先保存到链表，再统一输出。
3. 教师工资统计：统计教师人数、工资总额、平均工资、最高工资、最低工资，并按部门汇总。
4. 教师工资修改：可按教师编号修改职称和工资项目，适用于晋升职称后的工资调整。
5. 文件持久化：程序启动时自动读取历史数据，新增或修改后自动写回文件。

## 编译与运行

```bash
make
./tsms
```

也可以直接使用：

```bash
make run
```

## 数据格式

数据以 CSV 文本格式保存，每行一名教师：

```text
编号,姓名,性别,年龄,部门,职称,基本工资,岗位津贴,奖金,扣款
```

程序会根据工资项目自动计算应发工资：

```text
应发工资 = 基本工资 + 岗位津贴 + 奖金 - 扣款
```
