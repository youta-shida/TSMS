# 教师工资管理系统（C 语言课程设计）

本项目面向“程序设计基础”课程设计，围绕教师及财务处对教师工资管理的基本需求，完成一个可在 Windows MinGW GCC 环境下编译运行的小型教师工资管理系统。

## 一、需求分析

### 1. 系统目标

系统用于管理教师基本信息与工资信息，支持教师工资数据的录入、持久化保存、查询、统计与修改，帮助人事或财务管理人员完成基础工资管理工作。系统重点体现 C 语言程序设计基础中的结构体、文件读写、链表、函数划分、输入校验和菜单式交互。

### 2. 用户角色

- **财务处工作人员**：录入工资、查询工资、统计工资总额与平均工资。
- **人事/教务管理员**：维护教师编号、部门、职称等信息，在教师晋升职称或岗位调整后修改工资信息。
- **教师本人**：可通过教师编号查询个人工资信息（由管理员操作系统完成）。

### 3. 数据需求

每条教师工资记录包含以下字段：

| 字段 | 说明 |
| --- | --- |
| 教师编号 | 教师唯一标识，不允许重复 |
| 姓名 | 教师姓名 |
| 所在部门 | 学院、系部或行政部门 |
| 职称 | 助教、讲师、副教授、教授等 |
| 基本工资 | 固定工资部分 |
| 津贴 | 岗位、课时或生活补贴 |
| 奖金 | 绩效、课题或其他奖励 |
| 扣款 | 社保、个税或其他扣除 |
| 应发工资 | `基本工资 + 津贴 + 奖金 - 扣款`，由系统自动计算 |

数据以文件形式保存到 `teachers.dat`，程序再次运行时仍可继续读取和维护历史数据。

### 4. 功能需求

#### 4.1 教师信息及工资信息录入

- 录入教师编号、姓名、部门、职称、基本工资、津贴、奖金、扣款。
- 教师编号唯一，若编号已存在则拒绝重复录入。
- 工资相关字段必须为不小于 0 的数字。
- 录入成功后将记录追加保存到数据文件。

#### 4.2 教师工资查询

系统至少提供两种查询方式：

1. **按教师编号查询**：适合查询某一位教师的工资信息。
2. **按所在部门查询**：适合查询某个部门全部教师的工资信息。

查询结果会先保存到链表中，再统一输出，满足课程设计对链表使用的要求。

#### 4.3 教师工资统计

- 支持统计全部教师或指定部门。
- 输出统计人数、应发工资总额、平均应发工资、最高应发工资、最低应发工资。
- 统计结果用于财务处进行工资总量核算和部门工资分析。

#### 4.4 教师工资修改

- 按教师编号定位需要修改的记录。
- 支持修改姓名、部门、职称和工资项目。
- 适用于教师晋升职称、岗位调整、奖金变化、扣款变化等场景。
- 修改后重写数据文件，保证文件中的信息为最新数据。

#### 4.5 扩展功能

除题目要求外，系统还增加了以下实用功能：

- 浏览全部教师工资记录。
- 菜单中查看需求分析概要。
- 对菜单选择和数字输入进行校验，减少错误输入导致的程序异常。
- Windows 控制台 UTF-8 初始化，改善中文乱码问题。

### 5. 非功能需求

- **可移植性**：核心代码使用标准 C，Windows 控制台编码设置使用条件编译，仅在 `_WIN32` 下启用。
- **易用性**：采用中文菜单式交互，操作步骤清晰。
- **可靠性**：对文件打开、写入、临时文件替换等操作进行检查。
- **可维护性**：使用结构体表示教师记录，使用函数拆分录入、查询、统计、修改等模块。
- **编码兼容性**：源文件按 UTF-8 保存，Windows 运行时设置控制台输入输出为 UTF-8，减少中文显示乱码。

## 二、概要设计

### 1. 数据结构设计

- `Teacher` 结构体：保存一条教师工资记录。
- `ResultNode` 链表节点：保存查询结果，查询完成后遍历链表输出。

### 2. 文件设计

- 数据文件：`teachers.dat`
- 存储方式：二进制结构体记录顺序存储。
- 新增记录：以追加方式写入文件。
- 修改记录：读原文件，写临时文件 `teachers.tmp`，成功后替换原文件。

### 3. 模块设计

| 模块 | 主要函数 |
| --- | --- |
| 控制台与输入 | `setupConsole`、`readLine`、`readInt`、`readDouble` |
| 录入模块 | `addTeacher`、`isDuplicateId` |
| 查询模块 | `queryById`、`queryByDepartment`、`appendResult`、`printResults` |
| 统计模块 | `statistics` |
| 修改模块 | `modifyTeacher` |
| 浏览与菜单 | `listAll`、`menu`、`main` |

## 三、Windows 编译与运行

你的编译器版本为 MinGW GCC 14.2.0，可在 Windows 命令提示符或 PowerShell 中执行：

```bat
gcc -std=c11 -Wall -Wextra -O2 src\main.c -o tsms.exe
.\tsms.exe
```

如果控制台仍出现中文乱码，可先执行：

```bat
chcp 65001
```

并确认 `src/main.c` 使用 UTF-8 编码保存。程序内部已经在 Windows 下调用 `SetConsoleOutputCP(CP_UTF8)` 和 `SetConsoleCP(CP_UTF8)` 来尽量改善中文输入输出乱码。

## 四、Linux/macOS 快速检查

```sh
gcc -std=c11 -Wall -Wextra -O2 src/main.c -o tsms
./tsms
```
